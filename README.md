# prompt-library

A personal collection of reusable prompts for academic writing, coding, and AI agents.

## Structure

- `prompts/academic-writing/` — prompts for research and scholarly writing tasks
- `prompts/coding/` — prompts for debugging, implementation, and code quality workflows
- `prompts/ai-agents/` — prompts for multi-agent orchestration and delegation

## Usage

1. Pick a prompt file that matches your task.
2. Replace `{{placeholders}}` with your context.
3. Run the prompt in your preferred LLM or agent workflow.
