# 💻 Coding

Kumpulan prompt untuk workflow coding sehari-hari: debugging, refactor, code review, dan dokumentasi.

---

## 📂 Subfolder

| Folder | Deskripsi |
|--------|-----------|
| `debugging/` | Analisis error, stack trace, dan pemecahan masalah kode |
| `refactor/` | Perbaikan kualitas, struktur, dan keterbacaan kode |
| `code-review/` | Review Pull Request dan standar kode tim |
| `dokumentasi/` | Docstring otomatis, README generator, dan komentar kode |

---

## 📋 Daftar Prompt

| File | Deskripsi | Model yang Direkomendasikan |
|------|-----------|---------------------------|
| [`debugging/analisis-error-stack-trace.md`](./debugging/analisis-error-stack-trace.md) | Analisis mendalam error dan stack trace | GPT-4, Claude 3.5 |
| [`code-review/review-pull-request.md`](./code-review/review-pull-request.md) | Review Pull Request secara komprehensif | GPT-4, Claude 3.5 |

---

## 💡 Tips Penggunaan

- Selalu sertakan **seluruh** stack trace, bukan hanya baris terakhir
- Untuk code review, hapus informasi sensitif dari kode sebelum di-paste
- Sebutkan versi bahasa dan framework secara spesifik (misal: "Python 3.11", bukan hanya "Python")
