## [0.1.0] - 2026-10-01

### Added
- Struktur folder lengkap: `akademik/`, `coding/`, `agents/`, `templates/`, `docs/`
- `AGENTS.md` — panduan lengkap untuk AI agent yang bekerja di repo ini
- `README.md` — dokumentasi utama repo
- `LICENSE` — MIT License atas nama Fajar Geran Arifin
- `CONTRIBUTING.md` — panduan kontribusi
- `templates/prompt-template.md` — template standar untuk semua prompt
- Contoh prompt awal:
  - `akademik/penulisan-ilmiah/rapikan-abstrak-jurnal.md`
  - `coding/debugging/analisis-error-stack-trace.md`
  - `coding/code-review/review-pull-request.md`
  - `agents/system-prompts/coding-agent-safe.md`
  - `agents/agents-md-templates/generic-agents-md.md`
- `docs/prompt-engineering-tips.md` — 10 tips menulis prompt yang efektif
- `docs/naming-conventions.md` — aturan penamaan file dan folder
- GitHub templates: ISSUE_TEMPLATE dan PULL_REQUEST_TEMPLATE
